# WordPress preview conversion

The private WordPress.com preview for Mum Talks_WordPress was built from the Vercel production site at the revision recorded in [README.md](README.md).

WordPress captured 26 pages and reported 8 converted pages, 19 missing routes and a failed quality check. The preview homepage returned HTTP 200. The WordPress API rejected signed requests for this preview, so editing through the API was unverified. The import did not provide an installable theme or site export.

Before this can replace the Vercel site, recover the missing routes, check the original and rebuilt designs side by side, and verify page editing and the integrations listed in the README.
